# Sidebar Widget - Drag and Drop Testing

## Как протестировать drag and drop

### 1. Запуск режима редактирования
1. Откройте приложение
2. Найдите боковую панель (sidebar)
3. Нажмите и удерживайте любой элемент в течение 500ms
4. Должна появиться кнопка "Сбросить порядок" внизу
5. Нажмите на неё и выберите "Войти в режим редактирования"

### 2. Тестирование drag and drop
1. После входа в режим редактирования должны появиться кнопки "Применить" и "Отменить"
2. В правом верхнем углу FSM Debugger должен показывать:
   - Current State: EDIT_MODE
   - Drag: зеленый (активен)
   - Edit Controls: синий (активен)
3. Попробуйте перетащить элементы сайдбара
4. Должны появляться индикаторы размещения (тонкие линии с градиентом)
5. При отпускании элемента он должен переместиться в новую позицию

### 3. Отладка
- Откройте консоль разработчика (F12)
- При drag and drop должны появляться логи:
  - 🔍 Can drag - проверка возможности перетаскивания
  - 🔄 Drag started - начало перетаскивания
  - 🎯 Hover on - наведение на элемент
  - 🎯 Can drop on - проверка возможности размещения
  - 📦 Drop - размещение элемента
  - ✅ Drag ended - окончание перетаскивания

### 4. Ожидаемое поведение
- Drag and drop работает ТОЛЬКО в режиме редактирования (EDIT_MODE)
- В обычном режиме (NORMAL) drag недоступен
- В режиме долгого нажатия (LONG_PRESS) drag недоступен
- Элементы можно перетаскивать только на уровне 0 (основные элементы)
- Вложенные элементы не перетаскиваются
- Перетаскиваемый элемент становится полупрозрачным и слегка поворачивается
- Курсор меняется на "grab" в режиме редактирования и "grabbing" при перетаскивании

### 5. Проблемы и решения
Если drag and drop не работает:
1. Проверьте FSM Debugger - должен показывать EDIT_MODE
2. Проверьте консоль на наличие логов
3. Убедитесь, что элементы имеют `isDraggable: true`
4. Проверьте, что вы пытаетесь перетащить элемент уровня 0

## Дизайн и стили

### Обновленный дизайн (v2.0)
- **Строгий минималистичный стиль**: Убраны избыточные эффекты и яркие цвета
- **Квадратные иконки**: Все иконки теперь в квадратных контейнерах с закругленными углами
- **Приглушенные цвета**: Менее яркие цвета текста и фона для лучшей читаемости
- **Улучшенные кнопки**: Все кнопки имеют единообразный стиль с закругленными углами
- **Тонкие индикаторы**: Индикаторы размещения стали тоньше и менее навязчивыми

### Стили перетаскивания
- **Полупрозрачность**: Перетаскиваемый элемент становится полупрозрачным (opacity: 0.3)
- **Поворот**: Легкий поворот элемента (rotate: 2deg) для визуального эффекта
- **Масштаб**: Небольшое уменьшение (scale: 0.95) для эффекта "отрыва"
- **Курсор**: Автоматическое изменение курсора (grab/grabbing)

### Кнопки и элементы управления
- **Единообразие**: Все кнопки имеют borderRadius: 2 и высоту 32px
- **Иконки**: Размер иконок уменьшен до 18-20px для лучшей пропорции
- **Текст**: Уменьшен размер шрифта и яркость для менее навязчивого вида
- **Hover эффекты**: Мягкие переходы с transform: translateY(-1px)

## Архитектура

### FSM состояния
- **NORMAL**: Обычный режим, drag недоступен
- **LONG_PRESS**: Долгое нажатие, показывается кнопка сброса
- **EDIT_MODE**: Режим редактирования, drag доступен

### Компоненты
- **SidebarWidget**: Основной компонент с FSM логикой
- **SidebarItem**: Элемент с drag and drop функциональностью
- **FSMDebugger**: Отладочная панель (только в development)
- **DropIndicator**: Визуальные индикаторы размещения (обновлены)
- **EditControls**: Кнопки управления (обновлены)
- **SidebarResetButton**: Кнопка сброса (обновлена)
