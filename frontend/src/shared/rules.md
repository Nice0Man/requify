# Shared Layer Rules - Общий слой

## Назначение
Содержит переиспользуемые компоненты, утилиты, хуки и конфигурацию, которые используются во всех слоях приложения.

## Структура
```
shared/
├── api/           # Базовые API клиенты и конфигурация
├── components/    # Переиспользуемые UI компоненты
├── contexts/      # React контексты
├── hooks/         # Переиспользуемые хуки
├── lib/           # Настройка библиотек (i18n, router, store)
├── styles/        # Общие стили и темы
├── types/         # Общие типы TypeScript
├── ui/            # UI kit компоненты
└── utils/         # Утилитарные функции
```

## Правила

### 1. Независимость
- **НЕ МОЖЕТ** импортировать из: `entities`, `features`, `widgets`, `pages`
- **МОЖЕТ** импортировать: только внутри `shared` и внешние библиотеки

### 2. Переиспользуемость
- Все компоненты должны быть максимально переиспользуемыми
- Избегать привязки к конкретному бизнес-контексту
- Использовать композицию вместо наследования

### 3. API клиенты
- Использовать только `API_ENDPOINTS` для всех запросов
- Настройка базового HTTP клиента
- Типизация запросов и ответов

### 4. UI компоненты
- Следовать Material-UI Design System
- Поддержка темизации
- Accessibility (a11y) обязательно

### 5. Хуки
- Максимальная производительность
- Мемоизация где необходимо
- TypeScript типизация

### 6. Контексты
- Минимальное количество контекстов
- Оптимизация перерендеров
- Provider композиция

```typescript
// shared/ui/Button/Button.tsx

}

// shared/hooks/useApi.ts

  // React Query с типизацией

```

```typescript
// ❌ Импорт из верхних слоев

// ❌ Бизнес-логика в shared
export const validateUserData = (user: User) => {
  // Специфичная для пользователей логика
};
```
