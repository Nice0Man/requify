### 3. Добавление специализированных зависимостей
Созданы новые зависимости для более гранулярного контроля доступа:

#### Роле-ориентированные зависимости:
- `get_admin_user()` - только администраторы
- `get_manager_user()` - менеджеры и выше  
- `get_analyst_user()` - аналитики и выше
- `get_developer_user()` - разработчики и выше
- `get_tester_user()` - тестировщики и выше

#### Операционно-ориентированные зависимости:
- `get_spec_creator_user()` - создание спецификаций (аналитики+)
- `get_release_manager_user()` - управление релизами (менеджеры+)

### 4. Система ролей

#### Иерархия ролей:
```
Superuser > Admin > Manager > Analyst > Developer/Tester > User
```

#### Права доступа по ролям:

| Роль | Scopes | Основные возможности |
|------|--------|---------------------|
| **Superuser** | Все + `system:admin` | Полный доступ к системе |
| **Admin** | Все кроме системных | Управление пользователями, полный доступ к функциям |
| **Manager** | `users:read`, `projects:*`, `requirements:*`, `releases:*`, `testing:*`, `admin:read` | Управление проектами и требованиями |
| **Analyst** | `projects:*`, `requirements:*`, `releases:read`, `testing:read` | Работа с требованиями и спецификациями |
| **Developer** | `projects:read`, `requirements:read`, `releases:*`, `testing:read` | Работа с релизами |
| **Tester** | `projects:read`, `requirements:read`, `releases:read`, `testing:*` | Тестирование и интеграция с АСУТс |
| **User** | Только `read` scopes | Просмотр данных |
