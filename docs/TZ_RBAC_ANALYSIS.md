## ❌ Критические проблемы

### 1. **Отсутствует роль Product Manager (PM)**
**Проблема**: В ТЗ PM является ключевой ролью для управления требованиями, но в системе такой роли нет.

**ТЗ требует PM для:**
- Создания требований (функция 1)
- Редактирования требований (функция 3)  
- Архивирования требований (функция 4)
- Формирования релизов (функция 9)
- Формирования ТЗ к релизам (функция 10)
- Создания проектов (функция 13)
- Удаления проектов (функция 14)

**Текущее состояние**: Эти функции распределены между `manager`, `analyst` и `admin`.

### 2. **Неправильные права у роли Analyst**
**Проблема**: Analyst имеет права создания, но по ТЗ должен только читать.

**ТЗ требует**: Аналитик только читает требования и проекты
**Текущие права**: `projects:write`, `requirements:write` (создание и изменение)

### 3. **Отсутствует роль Senior Developer**
**Проблема**: ТЗ упоминает "Старший разработчик" как отдельную роль с расширенными правами.

### 4. **Расхождения между Frontend и Backend константами**
**Проблема**: В Frontend есть роли, которых нет в Backend:
- `PROJECT_MANAGER` (frontend) vs нет в backend
- `BUSINESS_ANALYST` (frontend) vs `analyst` (backend)
